# 🛡️ Internal SIH 2026 Admin Management Portal

Admin Dashboard web application built with **React**, **TypeScript**, and **Vite** for managing registrations, verifying teams, exporting reports, and configuring hackathon settings.

---

## 🌟 Key Features

- **Analytics Dashboard**: Real-time summary of total registrations, completed team applications, pending mentor submissions, and department-wise charts.
- **Team Management Table**: Dynamic table with search, department filtering, status toggling, pagination, and detailed modal views.
- **Excel & PDF Export**: One-click download of all team data in structured Excel (.xlsx) or formatted PDF reports.
- **System Settings Control**: Super Admin portal to open/close registration and update registration deadlines.
- **Audit Logs Viewer**: Track all administrative actions, timestamps, and IP addresses.

---

## 🚀 Quick Start

```bash
cd admin
npm install
npm run dev
```

The Admin portal runs by default on `http://localhost:3001`.
